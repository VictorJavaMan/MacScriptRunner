# MacScriptRunner

Нативное приложение для macOS 14+, которое показывает `.sh`-скрипты из выбранной папки, хранит примечания, запускает и останавливает процессы и выводит stdout/stderr в реальном времени.

## Запуск из Xcode

1. Откройте `Package.swift` в Xcode.
2. Выберите схему `MacScriptRunner` и нажмите Run.

## Сборка `.app`

```sh
chmod +x build-app.sh
./build-app.sh
open dist/MacScriptRunner.app
```

При первом запуске откройте **MacScriptRunner → Settings…**, выберите папку с `.sh`-файлами и тему оформления.

В тёмной теме выбранный скрипт отмечается мягкой полупрозрачной подсветкой, сохраняющей контраст названия и примечания.
Чтобы изменить примечание, дважды нажмите на пункт списка. Нажмите Enter или переведите фокус, чтобы закончить редактирование.
Одиночное нажатие переключает выбранный пункт без задержки. Выбор другого скрипта автоматически завершает редактирование текущего примечания.

Скрипт запускается через `/bin/zsh`, а его рабочей папкой становится папка самого скрипта. Вывод stdout и stderr объединяется в правой панели.
Если первая строка скрипта содержит `shebang`, приложение использует указанный интерпретатор; иначе применяется `/bin/zsh`. Поле под терминалом передаёт введённые строки в стандартный ввод запущенного скрипта.
